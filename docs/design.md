# Minion Adventure — Design (approved 2026-11-16)

## Intent
A funny, Twine-style choose-your-own-adventure in a single HTML file where the player helps Gru defeat a villain. For fun / personal play.

## Must include
Gru, Lucy, Margo, Edith, Agnes, Kyle the dog, the Minions, the fluffy unicorn, and the fart gun.

## Approaches
- **Hand-built single HTML file that plays like Twine (chosen):** double-click to play, no install, full control over look and jokes.
- Real Twine app (Harlowe/SugarCube): requires installing Twine and exporting; no gain for the player.
- .twee source only: needs tooling to play. Rejected.

## Design
- Villain: original — Dr. Snoozemonger, stealing every banana on Earth to power his Eternal Nap Ray.
- ~4 chapters, ~25–30 passages, 2–3 choices each; silly "fail" endings that loop back; a couple of real endings.
- Character beats: Lucy's lipstick taser, Margo's sarcasm, Edith wants explosions, Agnes + fluffy unicorn save the day, Kyle bites at the worst moment, Minions speak Minionese and cause chaos, fart gun used for comedy and as a weapon option.
- Stats: "Minion chaos" and "bananas recovered" counters that influence which ending you get.
- Restart button; retro Twine-ish styling.

## Left to the builder
Exact passage text, jokes, styling details. Original story — no recreation of movie plots.
